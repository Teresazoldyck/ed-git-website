# Green Bikes

This repository contains a website for Green Bikes, a fictional bicycle rental company located in the city centre. The company offers electric and mountain bikes for rent.

## Technologies

- HTML: used to structure the web page.
- CSS: used to style the web page.

## How to open the website

1. Download or clone this repository to your computer.
2. Open the `index.html` file in a web browser such as Chrome, Firefox or Edge.
